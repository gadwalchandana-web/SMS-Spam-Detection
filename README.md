# SMS Spam Detection

A Machine Learning project that classifies SMS messages as **Spam** or **Ham**.

## Project Overview

This project uses the UCI SMS Spam Collection dataset to build a text classification model.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab
- GitHub

## Machine Learning Workflow

1. Load the SMS dataset
2. Remove duplicate messages
3. Clean the text data
4. Convert labels into numerical values
5. Extract features using TF-IDF
6. Split data into training and testing sets
7. Train a Multinomial Naive Bayes model
8. Evaluate the model
9. Test the model with new SMS messages

## Model

**Multinomial Naive Bayes**

## Results

- Accuracy: **94.87%**
- Spam Precision: **1.00**
- Spam Recall: **0.60**
- Spam F1-score: **0.75**
